## Title lifecycle replay details

`TITLEIN.PAS` uses `{$M 49152,163840,655360}`, matching the memory directive in reconstructed `ZZT.PAS`; the smaller Turbo Pascal default stack caused runtime error 202 in the nested title selector/load path and did not model the original executable's stack. The R fixture is generated by direct Pascal `WorldSave('RESTORE', '.SAV')` from a title-only DEMO load, then consumed by the original `GameWorldLoad('.SAV')` path in a fresh DOSBox-X session.

Staging-only hooks suppress the blocking About modal, inject Enter at the existing `.SAV` selector boundary, inject one Escape after the selector's existing `InputUpdate` poll for the cancel/retry route, and stop/capture the real loops at the chosen checkpoints. The source `TextWindowSelect`, `GameWorldLoad`, `WorldLoad`, `WorldUnload`, `BoardClose`, and `GamePlayLoop` bodies run unchanged. The selector hook makes the single generated save row deterministic. The cancel/retry hook captures the actual title-loop cancel branch and queues R only after that branch; for the refused route, a separate test hook exits after the original `GameWorldLoad` returns false so the refusal state can be captured. RNG is seeded, logical time uses the existing SoundProbe clock, and sound output is captured without physical hardware.

## Reused verification

The clean Pascal/production run on 2026-11-26 exited 0 with **134/134** direct Turbo Pascal sessions (54 standard and 80 standalone), **58/58** configured Pascal-to-production differential invocations, and all ten frozen integrated fixtures passing. F01–F10 matched 238 checkpoints, 824,821 state fields, and 169/169 logical-cycle snapshots. The P title replay matched at 3 checkpoints / 10,242 fields, successful R restore at 3 / 10,287, cancel-then-retry at 4 / 13,716, and unsupported-version R refusal at 3,385 of 3,386 comparable world/board/stat/tile fields. `World.BoardLen[0]` was 319 in Pascal and 327 for LibZoo's augmented private buffer, so this internal representation size is excluded from equality; the file-format suite compares serialized bytes separately. The exact 512-byte malformed `.SAV` returned `ZOO_ERROR_WRONGVER (-3)` in production. The frozen integrated corpus remains 10/10; no new fixtures or acceptance IDs were added. The recorded DOSBox-X executable is 2026.10.01 with SHA-256 `072C1944635CCC545A816E128625E3405FEAB559021E4EF60B2D512F97F754C0`.

The refusal differential exposed that `zoo_world_restore` returned from a failed title restore while retaining the monitor tile, whereas Pascal's `GamePlayLoop` has restored the player tile before `GameTitleLoop` handles `R`. The shared restore entry point now establishes that source-defined title state before loading, so the refused transition matches.

The P route's queued `P`/`X` behavior preserves the original `InputUpdate` buffer truncation in both implementations. The R route's deterministic Enter input is injected only at the selection boundary; it does not replace the title menu or loading routines. `tools/runtime-compat/tick_exit.c::run_game_start_enter_checks` remains supplemental production-only evidence and is not counted as D or DP.
