## Title lifecycle replay details

`TITLEIN.PAS` uses `{$M 49152,163840,655360}`, matching the memory directive in reconstructed `ZZT.PAS`; the smaller Turbo Pascal default stack caused runtime error 202 in the nested title selector/load path and did not model the original executable's stack. The R fixture is generated by direct Pascal `WorldSave('RESTORE', '.SAV')` from a title-only DEMO load, then consumed by the original `GameWorldLoad('.SAV')` path in a fresh DOSBox-X session.

Staging-only hooks suppress the blocking About modal, inject Enter at the existing `.SAV` selector boundary, inject one Escape after the selector's existing `InputUpdate` poll for the cancel/retry route, and stop/capture the real loops at the chosen checkpoints. The source `TextWindowSelect`, `GameWorldLoad`, `WorldLoad`, `WorldUnload`, `BoardClose`, and `GamePlayLoop` bodies run unchanged. The selector hook makes the single generated save row deterministic. The cancel/retry hook captures the actual title-loop cancel branch and queues R only after that branch; for the refused route, a separate test hook exits after the original `GameWorldLoad` returns false so the refusal state can be captured. RNG is seeded, logical time uses the existing SoundProbe clock, and sound output is captured without physical hardware.

Thus this comparison checks callback outcomes under controlled services, not file-backed board loading or the actual production `zoo_board_enter` routine. `World.BoardLen[0]` remains implementation-specific and the empty-file route also excludes `InputKeyPressed` because the original modal consumes Escape after the engine refusal; serialized bytes are compared separately. The exact 512-byte malformed `.SAV` returned `ZOO_ERROR_WRONGVER (-3)` and the empty `.SAV` returned `ZOO_ERROR_INVAL (-2)` in production. The frozen integrated corpus remains 10/10; no new fixtures or acceptance IDs were added. The recorded DOSBox-X executable is 2026.10.01 with SHA-256 `B8D6A5D0FB7C6C3BB4CE18BB3E306EED77F0865B898E262322AC94C7D11971D3`.

The refusal differential exposed that `zoo_world_restore` returned from a failed title restore while retaining the monitor tile, whereas Pascal's `GamePlayLoop` has restored the player tile before `GameTitleLoop` handles `R`.
